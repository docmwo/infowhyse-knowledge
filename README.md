# Infowhyse Knowledge Platform (IKP)

## Ziel
Dieses Repository entwickelt eine AI-First-Wissensplattform für elektronische Abstimmungen,
Audience Response Systeme (ARS), TED-Systeme und professionelle Abstimmungslösungen.

## Leitprinzipien
- Fachwissen statt Marketing
- Probleme vor Produkten
- DACH-Fokus
- Wiederverwendbare Markdown-Inhalte
- Grundlage für Website, FAQ, Glossar, ai.txt und llms.txt
