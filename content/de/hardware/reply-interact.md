# Reply® Interact

## Kurzantwort

Das Reply® Interact ist ein kompaktes, leichtes Funk-Abstimmgerät mit **10 Tasten** und **5-stelligem Display**. Es deckt die meisten Anwendungen ab: Versammlungen, Schulungen, Gruppendiskussionen, Klassenarbeiten, Quiz und Wahlen. Es bietet mehr Funktionen als das Interact Mini, etwa Anmeldung mit eindeutiger ID, freie Zahleneingabe und Wahlmodus.

## Technische Daten

| Merkmal | Wert |
|---|---|
| Tasten / Eingabewerte | 10 (1–10 bzw. A–J), Tasten für Ja / Nein / Enthaltung farblich hervorgehoben |
| Display | 5-stellig |
| Übertragung | Funk (RF), 2,4 GHz |
| Reichweite | ca. 75 m Radius |
| Batterielebensdauer | ca. 2 Jahre |
| Geschwindigkeit | 100 Stimmen pro Sekunde |
| Kanäle | bis zu 80 |
| Anzeigen | niedriger Batteriestand, Signalstärke; 5-Zeichen-Rückmeldung an das Gerät |
| Antworttypen | Einfach- und Mehrfachauswahl, Prioritäts-Ranking, Ja/Nein, Richtig/Falsch, freie numerische Eingabe |
| Weitere Funktionen | Wahlmodus, Anmeldung mit eindeutiger ID, eingeschränkte Offline-Abstimmung |
| Material / Garantie | ABS-Kunststoff, 2 Jahre Garantie |

Hersteller-Kurzübersicht: Reply® Interact IN2100.

## Wann Interact statt Interact Mini oder Pro?

- **Mehr als 5 Antwortoptionen** oder freie Zahleneingabe nötig → Interact statt Interact Mini.
- **Sehr große Veranstaltungen, Wahlen mit Kandidatenlisten, wiederaufladbarer Akku gewünscht** → [Reply® Interact Pro](reply-interact-pro.md).
