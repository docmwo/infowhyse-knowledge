# What is an audience response system (ARS)?

## Short answer

An **audience response system (ARS)** captures, transmits, evaluates and displays answers or votes from a group in real time. Typical systems use **wireless keypads ("clickers")**, a receiver (base station) and software on a PC. In German-speaking countries the same technology is called a TED system or electronic voting system. Modern systems can also accept votes from smartphones via a browser.

## Components

1. **Input devices:** keypads (clickers) or browser access on smartphones, tablets and laptops
2. **Receiver / base station** connected to the PC by USB or Ethernet
3. **Software** to manage participants, voting rights, weights, questions and reports (for example EdiVote®, BoardARS™, CouncilARS™)
4. **Result display** on a projector, screen or LED wall
5. **Reports** in formats such as Excel, PDF or text

## How it works

1. Participants answer using their keypad.
2. The response is sent by radio (encrypted) to the base station and the keypad receives a confirmation.
3. The base station passes the data to the software, which shows the result immediately.

No internet connection is needed for keypad voting.

## Typical uses

- **Formal votes:** AGMs, board and member meetings, council sessions, elections
- **Live polling and feedback:** conferences, events, meetings
- **Training and education:** quizzes, knowledge checks, classroom voting
- **Entertainment:** TV shows, game formats, stage events

## Keypads or smartphones?

Keypads are preferred for critical votes, weak networks, mixed audiences and to avoid distraction. Smartphones suit remote participants and smaller groups. Hybrid combines both. See [Keypads vs smartphones](keypads-vs-smartphones.md).
