# Voting keypads vs smartphones

## Short answer

Use **keypads** for formal or critical votes, weak or restricted networks, mixed-age audiences, and when distraction must be avoided. Use **smartphones** (Reply® BYOPAD™) for remote participants and smaller or informal events. Use **both** (hybrid) when on-site and remote participants vote together.

## Comparison

| Criterion | Keypads (Reply® Interact) | Smartphones (Reply® BYOPAD™) |
|---|---|---|
| Internet / Wi-Fi | not needed, radio to PC | required for presenter and audience |
| Distraction | low | email, messaging and notifications |
| Ease of use | press a button, all ages | open browser, enter event code |
| App install | none | none, runs in the browser |
| Device handout | yes | no |
| Remote participants | not without add-on | yes |
| Data | stays on the organiser's PC | votes pass through a server; session data deleted after the session |
| Cost for very large groups | buy or rent devices | typically lower |

## Recommendations

**Choose keypads when** votes are legally relevant (resolutions, elections, council votes), the network is unreliable or locked down, participants are mixed in age and tech skills, or focus matters (presentations, training).

**Choose smartphones when** people join online, groups are small, or handing out devices is impractical.

**Choose hybrid when** presence and remote participants must vote in one result: see [Hybrid voting with BYOPAD](../solutions/hybrid-voting-byopad.md).

## Common mistakes

- Planning smartphone voting without testing the venue network
- Using easy-to-guess event codes for sensitive sessions (use a session password or individual passwords)
- Handing out keypads without linking them to participants
