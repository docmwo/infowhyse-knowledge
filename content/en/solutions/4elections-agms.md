# 4elections™ for AGMs and general meetings

## Short answer

**4elections™** is Infowhyse's voting and election software for **AGMs, general meetings and shareholder meetings**, and for any meeting with **complex elections, free quorums, several election modes and more than one weighting**. It works **offline only** with Reply® keypads (Interact Mini, Interact, Interact Pro). For simpler meetings and hybrid voting see [BoardARS™](boardars-board-meetings.md).

## Features

- Free choice of quorum to set the required majority
- Different weights per keypad, more than one weighting
- Elections with one or several candidates, election modes, quorums applied automatically, several rounds with one click
- Network-based registration front end and overview of shares or participants present
- Postal vote handling
- Open, named or secret voting
- Detailed logging of each voting event
- Result preview for the returning officer, transparent display for participants
- Print-ready reports in Rich Text Format right after the election, no database needed

## BoardARS™ or 4elections™?

| | BoardARS™ | 4elections™ |
|---|---|---|
| Audience | simple member meetings, board meetings, associations | plus general meetings, AGMs, shareholder meetings |
| Elections | single election up to 5 people | complex elections, several rounds and modes |
| Weightings | one | more than one |
| Quorums | simple voting logic | freely selectable |
| Online / hybrid (BYOPAD™) | yes | no, offline only |
